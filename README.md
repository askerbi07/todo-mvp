# To-Do List · MVP

Простой To-Do List: добавление, отметка выполненных, удаление, сохранение в localStorage.

## Стек
Vanilla HTML/CSS/JS, без сборки. Открывается через `npx serve .` или как статика.

## Как использовались AI-инструменты

1. **Архитектура** — GPT 6.2 Astra . Промт с жёсткими контрактами модулей,
   ≤100 строк на файл, classic deferred scripts вместо ES-модулей (чтобы работало и с `file://`).
   Результат — `docs/ARCHITECTURE.md`.
2. **Реализация** — локальные Qwen 3.8 Flash Next coder (200k) и Qwen 3.8 27B opus5.5-gpt6astra-grok4.7-dsv4pro-k3 (70k) через OpenCode.
   Каждый шаг раздела F скармливался отдельным промтом: один шаг = один файл.
   27B отдан на контроллер (`js/app.js`) — там самая тонкая логика (двойной listener,
   порядок `tasks = next` → `paint()`, восстановление фокуса).
3. **Ревью** — DeepSeek v4.1 Flash
